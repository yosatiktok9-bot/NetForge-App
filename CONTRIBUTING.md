# Contributing to NetForge

Thanks for interest in NetForge.

## Dev setup

1. JDK 17+
2. Android Studio 2024.1+ / SDK 34
3. `./gradlew assembleDebug`

## Code style

- Kotlin official style
- Compose Material 3
- No secrets in repo

## PRs

- Branch from `main`
- Keep commits focused
- CI must pass
